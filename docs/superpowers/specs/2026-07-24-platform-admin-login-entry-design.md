# 普通登录页增加平台管理员入口设计

## 目标

在普通公司用户登录页 `/login` 增加一个清晰但不抢占主操作的平台管理员入口，跳转到现有 `/platform/login`。该入口编译进同一前端产物，因此本地开发部署和生产部署行为一致。

## 交互设计

- 保留公司用户登录表单和主按钮不变。
- 在“登录”按钮下方增加轻量分隔区域。
- 显示文字链接“平台管理员入口”，并附带简短说明“用于公司开通与域名管理”。
- 点击后使用 React Router 导航到 `/platform/login`，不刷新整页。
- 平台入口不自动携带、转换或清理公司用户 token；平台登录继续使用独立 `platform_token`。
- 在移动端保持居中布局、可见键盘焦点和足够的点击区域。

## 安全与部署边界

- 入口只是公开导航链接，不改变平台认证、授权或 API 权限。
- 平台管理员仍必须通过独立平台登录接口认证。
- 不在页面中显示平台管理员邮箱、密码或账号是否存在。
- 本地和生产使用同一代码，无环境开关；生产环境更新前端镜像后自动出现入口。

## 测试与验收

- 登录页渲染“平台管理员入口”和用途说明。
- 点击入口后路由切换到 `/platform/login`。
- 公司登录表单原有提交、公司锁定和错误重试测试保持通过。
- 完整前端测试和生产构建通过。
- 本地 Docker 重建前端后，`/login` 与 `/platform/login` 均返回 HTTP 200。
